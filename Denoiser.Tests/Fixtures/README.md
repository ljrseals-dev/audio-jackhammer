# Test Fixtures

## synthetic_2s_440_660_seed42.wav

- 2 s, 48 kHz, mono
- 440 Hz + 660 Hz sine at −6 dBFS + white noise at −30 dBFS
- Noise seeded with `System.Random(42)` / Python `random.Random(42)` — deterministic
- Generated by `SyntheticAudio.Generate2s440_660_Seed42()` or `--regenerate-golden`
- **Never hand-edit**

## construction_sample.wav

- 2 s, 48 kHz, mono
- 0–1 s: construction-like noise only (broadband + impulses)
- 1–2 s: speech-like formants + same noise
- **Source:** self-generated synthetic (CC0). Not real site audio.
  For production validation, replace with FSD50K (CC-BY) construction noise
  mixed with LibriSpeech (CC-BY 4.0) at ~0 dB SNR and update this README.

## ola_off_golden_null.wav

- Used for golden regression when RNNoise native library is unavailable.
- Generated by the test suite / CLI regenerate path.
- **Never hand-edit** after committing.

## Regenerating goldens

```
dotnet run --project Denoiser.Cli -- --regenerate-golden --confirm-golden-regen
```

**Warning:** Only regenerate from a known-good baseline. Running on a
post-refactor branch that intentionally changed output silently defeats
the regression test. Always require `--confirm-golden-regen`.

## ola_off_golden_stub.wav

- Output of `DeterministicStubModel` (y[n]=0.9x[n]-0.1x[n-1]) on the synthetic fixture
  with `--ola off --lookahead off --highpass 90`.
- Pins model handoff / frame boundaries independently of Null identity.
- Generated by first test run; commit after verifying.

## DeepFilterNet env vars (ship gate)

- `DEEP_FILTER_NET_MODEL` — path to single-graph `deepfilter.onnx`
- `DEEP_FILTER_NET_AUX` — path to `deepfilter-auxiliary.bin` (ERB matrices + window)

Without these, DFN continuity / E2E tests skip. DFN must not ship to users until
`Dfn_SynthesisContinuity_AfterWarmup` is green with real weights.

Algorithmic delay: 1440 samples (30 ms) = 480 STFT + 2×480 lookahead.

## STRICT_SKIPS

Set `STRICT_SKIPS=1` in CI so missing weights/fixtures fail instead of skip.
Filter weights-gated tests with `--filter Category!=RequiresWeights` for lenient runs.
